# Launcher wallpapers

The fifteen entries in `SOURCES.json` each have a background JPEG and a thumbnail. Since v1.2.3 all glass, panel and backdrop surfaces blur the active wallpaper live with CSS; no pre-blurred material JPEGs are shipped. All derived images retain the source photograph's terms.

Photo pages, authors and licence observations are in [asset sources](../../../docs/asset-sources.md). Generation instructions are in [asset generation](../../../docs/assets.md). Full-size originals remain outside the repository.
